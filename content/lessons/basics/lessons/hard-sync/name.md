# Hard sync

With [sync](enth:osc2.sync) on, osc2 restarts its wave each time osc1 starts a cycle. So osc2 can only repeat at osc1's
pitch: its [semitones](enth:osc2.semi) no longer move the note but reshape the tone, and higher tunings tear harder,
like a voice.

Here osc1 is silent but still the master. Sync does nothing on osc1 itself, and whole octaves barely change the sound.
