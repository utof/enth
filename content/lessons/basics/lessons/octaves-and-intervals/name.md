# Semitones

[Semitones](enth:osc1.semi) moves the oscillator's pitch away from the note you play. Twelve semitones make an
**octave**: the same note name, higher or lower, so +12 turns a C3 into a C4. Seven make a **fifth**, the most open,
stable step after the octave.

Positive values go up and negative ones down, four octaves each way.
