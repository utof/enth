# Retrigger or free

- [Phase mode](enth:lfo1.phase_mode): how each cycle start is chosen: reset (the phase knob at each note-on), free
  (random per render) or seeded (from the seed).
- [Start phase](enth:lfo1.phase): where in its cycle the LFO starts in reset mode.
- [Seed](enth:lfo1.seed): the random seed used in seeded mode, including the random shapes.
