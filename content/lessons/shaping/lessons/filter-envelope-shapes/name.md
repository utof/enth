# The envelope's shape

env2 has the same four controls as the amplitude envelope; routed to the cutoff, they shape the brightness.

- [Attack](enth:env2.attack): how fast the filter opens.
- [Decay](enth:env2.decay): how fast it falls to the sustain level.
- [Sustain](enth:env2.sustain): how far it stays open while the note is held; 0 % makes a pluck.
- [Release](enth:env2.release): how it closes after the note ends.
