# The wavetable oscillator

wt1 plays one wave from a table of many, so moving through the table changes the timbre while the note
stays.

- [Table](enth:wt1.table): which set of waves: basic shapes, FM sweeps, a formant sweep, metal.
- [Position](enth:wt1.position): where in the table; route an LFO or MSEG here and the bass moves.
- [Semi](enth:wt1.semi) and [Level](enth:wt1.level): pitch and volume, as on any oscillator.
