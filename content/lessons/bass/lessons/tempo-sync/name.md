# Tempo sync

Bass music moves in time with the drums, so its LFOs count beats, not hertz.

- [Sync](enth:lfo1.sync): on, and the speed follows the song's tempo.
- [Beats](enth:lfo1.beats): one cycle per 1/4, 1/8, 1/16 and so on; T is a triplet, D dotted.
- [One-shot](enth:lfo1.one_shot): one cycle at each new note, then hold: a movement that hits once.

Change Beats from note to note and the drop starts talking.
